\chapter{Next steps}
\label{ch:next}

The manual pages describe everything that this tutorial omits:

\begin{description}
\item[\texttt{cinq(1)}] The command line.
\item[\texttt{cinq(5)}] The configuration file, the keymaps, every key, and the
  OSC commands that cinq takes.
\item[\texttt{cinq-show(5)}] Show files, outputs, cue settings, the file
  formats that each kind of cue plays, the stage window, the light patch and
  its output, and the messages of network cues.
\end{description}

Besides the storm show and the lights show of Chapter~\ref{ch:lights}, the
demo holds two more shows.  \texttt{chains.cinq.toml} fires a series of
knocks with one GO, using auto-continues, auto-follows, a wait, and a stop
cue.  \texttt{lists.cinq.toml} has a main list and a list of effects.

To report a problem or request a feature, open an issue in the tracker:

\begin{verbatim}
https://github.com/yzhou216/cinq/issues
\end{verbatim}
