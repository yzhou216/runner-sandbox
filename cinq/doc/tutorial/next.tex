\chapter{Next steps}
\label{ch:next}

The manual pages describe everything that this tutorial omits:

\begin{description}
\item[\texttt{cinq(1)}] The command line.
\item[\texttt{cinq(5)}] The configuration file, the keymaps, and every key.
\item[\texttt{cinq-show(5)}] Show files, cue settings, the file formats that
  each kind of cue plays, and the stage window.
\end{description}

The demo holds two more shows.  \texttt{chains.cinq.toml}
fires a series of knocks with one GO, using auto-continues, auto-follows, a
wait, and a stop cue.  \texttt{lists.cinq.toml} has a main list and a list of
effects.

To report a problem or request a feature, open an issue in the tracker:

\begin{verbatim}
https://github.com/yzhou216/cinq/issues
\end{verbatim}
